# Erynfetch

Мінімалістичний інструмент для виводу системної інформації в Linux. Написаний на Python без зовнішніх залежностей.

## Можливості

- Логотип ОС (Arch, Ubuntu, Debian, Tux для інших дистрибутивів)
- Інформація: ОС, ядро, архітектура, час роботи, оболонка, процесор, ОЗП, диск
- Кольоровий вивід, який вимикається, якщо вивід не у терміналі або встановлено змінну `NO_COLOR`

## Вимоги

- Linux
- Python 3.9 або новіший

## Встановлення

```bash
git clone https://github.com/TWOJ_NICK/fetch.git
cd myfetch
chmod +x myfetch.py
```

Щоб запускати командою з будь-якого місця, створи символічне посилання:

```bash
mkdir -p ~/.local/bin
ln -s "$(pwd)/myfetch.py" ~/.local/bin/myfetch
```

Переконайся, що `~/.local/bin` є у `PATH`.

## Використання

```bash
./myfetch.py
```

або, після встановлення посилання:

```bash
myfetch
```
